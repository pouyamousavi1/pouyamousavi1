## About

I'm a full-stack developer who turns messy financial data into clear, decision-ready dashboards, and ships AI products from idea to production. My work spans AI-assisted finance tools, treasury analytics for NGOs, and platforms built for real communities — most of it living in private repos, which is why this profile is quieter than the commit history behind it.

I build with an AI-first workflow: LLMs are both a feature in what I ship (transaction categorisation, retrieval-grounded assistants) and a force multiplier in how I ship it.

## Selected Work

Most of these are private repositories built for organisations or personal use.

### AI Products

| Project | What it does | Stack |
| :-- | :-- | :-- |
| **Synapse** | AI study assistant for university students — connects to Canvas, extracts every assignment, and answers questions grounded in the actual lecture slides, textbook, and subject outline. Includes a browser extension. | Next.js · Claude · OpenAI · Supabase · Stripe |
| **Personal Finance Analyser** | Ingests Australian bank statements, uses Claude to categorise every transaction, builds income and expenditure statements per financial year, and estimates the ATO tax position. | Next.js · Vercel AI SDK · Drizzle · Postgres |

### Financial & Treasury Tooling

| Project | What it does | Stack |
| :-- | :-- | :-- |
| **Treasury Analytics Platform** | Analytics for a national organisation — a Python ETL parses official spreadsheet reports into a dashboard of donations across funds, budget vs actual, year-over-year trends, and participation patterns. Deployed on Azure Container Apps. | Python · Next.js · Azure · Docker |
| **Regional Expenditure Analysis** | Interactive dashboard analysing regional spending against budgets, with custom fiscal-year handling. | Python · Next.js · Power BI |
| **Report Automation** | Headless automation that logs into a finance portal on a schedule, generates the week's reports, and files dated archives automatically. | Python · launchd |

### Community Platforms

| Project | What it does | Stack |
| :-- | :-- | :-- |
| **Unite** | SMS-first guest management for weddings — invitations by text, one-tap RSVP links, automated staged reminders for non-responders, and caterer-ready guest exports. | Next.js · Stripe · Supabase · Resend |
| **NSW/ACT Community Map** | Interactive map of every suburb and town across NSW and the ACT, overlaying community data with 2021 ABS Census demographics. | MapLibre GL · Turf · Supabase · Puppeteer |
| **Sydney Bahá'í Website** | Official website for the Sydney Bahá'í community — content, contact flows, authentication, and admin tooling. | Next.js · Prisma · Auth.js · Tailwind |
